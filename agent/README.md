# Agent Skills for PocketOne

[Agent Skills](https://agentskills.io) that teach coding agents (Claude Code, Cursor, Codex, Gemini CLI and others) to
build with PocketOne and PocketPages v1. This folder is a Claude Code plugin, listed in the repo's
[marketplace](../.claude-plugin/marketplace.json).

| Skill | Use it for |
|---|---|
| [pocketone](skills/pocketone/SKILL.md) | The `pocketone` binary, `pocketone.yaml`, every extension, and writing an extension with contracts |
| [pocketpages](skills/pocketpages/SKILL.md) | PocketPages v1 sites in `pb_pages/`: routing, `ctx`, templates, layouts, auth, deploying |

## Install

**Claude Code**

```
/plugin marketplace add pockethost/pocketone
/plugin install pocketone@pocketone
```

**Any Agent Skills tool**

```bash
npx skills add pockethost/pocketone
```

## Keeping them current

- `SKILL.md` files are written by hand. When a change makes one wrong (a renamed command, a new extension, a changed
  `ctx` member), fix it in the same change.
- Everything under `skills/*/reference/` is generated by `site/sync` from the pocketone.dev docs pages (the
  `pocketpages` skill gets the part under `/docs/extensions/pages`: `ext/pages/README.md`, its guides such as
  `SPEC.md`, and `ext/pages/site`). Don't edit it; edit the page and run `cd site/sync && go run .`. CI fails when it's
  stale. The same run writes pocketone.dev's `llms.txt` and `llms-full.txt`.
