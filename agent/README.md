# Agent Skills for PocketOne

[Agent Skills](https://agentskills.io) that teach coding agents (Claude Code, Cursor, Codex, Gemini CLI and others) to
build with PocketOne and Pages. This folder is a Claude Code plugin, listed in the repo's
[marketplace](../.claude-plugin/marketplace.json).

| Skill | Use it for |
|---|---|
| [pocketone](skills/pocketone/SKILL.md) | Using PocketOne in an app: the `pocketone` binary, `pocketone.yaml`, deploying, every extension, and the app's pages in `pb_pages/` ([pages.md](skills/pocketone/pages.md): routing, `ctx`, templates, layouts, auth) |
| [pocketone-extensions](skills/pocketone-extensions/SKILL.md) | Writing an extension and contributing it as a pull request to `ext/<name>/`: contracts, `extkit`, tests, README |

## Install

**Claude Code**

```
/plugin marketplace add pocketonehq/pocketone
/plugin install pocketone@pocketone
```

**Any Agent Skills tool**

```bash
npx skills add pocketonehq/pocketone
```

## Keeping them current

- `SKILL.md` files (and `skills/pocketone/pages.md`) are written by hand. When a change makes one wrong (a renamed command, a new extension, a changed
  `ctx` member), fix it in the same change.
- Everything under `skills/*/reference/` is generated by `site/sync` from the pocketone.dev docs pages
  (`pocketone-extensions` gets the extension guide, the contracts and the extension catalogue; `pocketone` gets the
  rest, the Pages docs under `/docs/extensions/pages` included). Which pages each skill gets is `docsSites` in `site/sync/agent.go`. Don't edit it; edit the page and run `cd site/sync && go run .`. CI fails when it's
  stale. The same run writes pocketone.dev's `llms.txt` and `llms-full.txt`.
