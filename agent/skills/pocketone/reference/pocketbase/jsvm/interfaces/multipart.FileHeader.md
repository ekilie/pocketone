# Interface FileHeader

A FileHeader describes a file part of a multipart request.

**Hierarchy**

- FileHeader

## Methods

### open

```ts
open(): multipart.File
```

Open opens and returns the [FileHeader]'s associated File.

**Returns multipart.File**
