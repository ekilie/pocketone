# Interface Renderer

Renderer defines a single parsed template.

**Hierarchy**

- Renderer

## Methods

### render

```ts
render(data): string
```

Render executes the template with the specified data as the dot object and returns the result as plain string.

**Parameters**

- `data: any`

**Returns string**
