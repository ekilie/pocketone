# Interface UIExtension

**Hierarchy**

- UIExtension

## Properties

### fs

```ts
fs: FS
```

FS is the extension file system.

### name

```ts
name: string
```

Name is the name of the extension. It is also used as path segment for the registered public extension endpoint (e.g. /_/extensions/{name}/*)
