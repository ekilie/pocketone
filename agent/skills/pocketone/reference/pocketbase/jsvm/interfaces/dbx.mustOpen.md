# Interface mustOpen

**Hierarchy**

- mustOpen

```ts
mustOpen(driverName, dsn): dbx.DB
```

MustOpen opens a database and establishes a connection to it. Please refer to sql.Open() and sql.Ping() for more information.

**Parameters**

- `driverName: string`
- `dsn: string`

**Returns dbx.DB**
