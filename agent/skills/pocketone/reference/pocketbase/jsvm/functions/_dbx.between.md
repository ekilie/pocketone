# Function between

```ts
between(col, from, to): Expression
```

Between generates a BETWEEN expression. For example, Between("age", 10, 30) generates: "age" BETWEEN 10 AND 30

**Parameters**

- `col: string`
- `from: {}`
- `to: {}`

**Returns Expression**
