# Function notBetween

```ts
notBetween(col, from, to): Expression
```

NotBetween generates a NOT BETWEEN expression. For example, NotBetween("age", 10, 30) generates: "age" NOT BETWEEN 10 AND 30

**Parameters**

- `col: string`
- `from: {}`
- `to: {}`

**Returns Expression**
