# tls/v1

The TLS of a multisite host's main listener. Its provider hands the host a `tls.Config` (certificates on demand,
for hostnames an instance serves) and, for HTTP challenges, a wrapper for the plain-HTTP listener. With no provider
the host uses the certificate files in its `server` section, or plain HTTP.

A host-scope service contract, one provider ([tls.go](tls.go)).

## Use

Nothing to call: the host's listener uses it. Turn the provider on in its own section (`autotls: { auto: true }`).

## Provide

Implement `tlsv1.Provider` and provide it in a host extension's `RegisterHost`; only issue certificates for
hostnames `served` reports true for.

```go
tlsv1.Contract.ProvideIn(h.Scope, myTLS)
```
