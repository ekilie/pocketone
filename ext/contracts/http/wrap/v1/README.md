# http.wrap/v1

Middleware around everything a multisite host serves: health, every instance, forwarded requests. Wrappers nest in
provider order, the first outermost (a Server-Timing header first, so it measures everything inside it).

A host-scope service contract, many providers in order ([wrap.go](wrap.go)).

## Use

Nothing to call: the host wraps its handler with every provider. Order them in `pocketone.yaml` if needed:

```yaml
providers:
  http.wrap/v1: [servertiming]
```

## Provide

Implement `wrapv1.Wrapper` (`Wrap(next http.Handler) http.Handler`) and provide it in a host extension's
`RegisterHost`:

```go
wrapv1.Contract.ProvideIn(h.Scope, myWrapper)
```
