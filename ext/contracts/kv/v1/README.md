# kv/v1

An app's key-value store: a name and a JSON value, kept without a collection or a migration. Use it for an app's
settings, a feature's state, anything that is one blob rather than many records. Each value is a row in PocketBase's
own `_params` table, so it rides along in backups.

A wire contract ([kv.go](kv.go)) plus Go helpers ([helpers.go](helpers.go)).

## Use

**From Go** (an extension, a hook), call the helpers. They need no provider and work inside a transaction when given
one:

```go
var s Settings
found, err := kvv1.Get(app, "storytime/settings", &s) // found is false and s untouched when there's no value
err = kvv1.Set(app, "storytime/settings", s)          // any value json.Marshal takes
err = kvv1.Delete(app, "storytime/settings")          // no error when there was no value
entries, err := kvv1.List(app, "storytime/")          // by name prefix, sorted by name; "" lists all
e, found, err := kvv1.Lookup(app, "storytime/settings") // the raw entry, with created and updated
```

Declare `WorksWith: extkit.IDs("kv/v1")` when you do.

**From page code and pb_hooks**, the provider gives `$kv` (sync, local):

```js
const settings = $kv.get("storytime/settings") ?? defaults // the parsed value, or null
$kv.set("storytime/settings", { title: "Story Time", minutes: 10 })
$kv.delete("storytime/settings")
$kv.list("storytime/") // [{ name, value, created, updated }]
```

**Over HTTP** (superusers, or an API token with the scope):

| Operation | HTTP | Token scope |
|---|---|---|
| List | `GET /api/_c/kv/v1?prefix=storytime/` | `kv:read` |
| Get | `GET /api/_c/kv/v1/get?name=storytime/settings` | `kv:read` |
| Set | `POST /api/_c/kv/v1/set` with `{"name": "storytime/settings", "value": {...}}` | `kv` |
| Delete | `POST /api/_c/kv/v1/delete` with `{"name": "storytime/settings"}` | `kv` |

Get answers `404 not_found` for a name with no value. The same operations are `pocketone remote kv ...` commands and
MCP tools (`kv_list`, `kv_get`, `kv_set`, `kv_delete`).

**Names** are 1 to 128 characters: letters, digits and `_ - . : /`, starting with a letter or digit. Start yours with a
prefix of your own (`storytime/`, `myext:`) so they stay apart from other apps' and extensions'. A value is any JSON up
to 1 MiB.

**Storage:** name `storytime/settings` is the `_params` row with id `kv:storytime/settings`, its value the row's
`value`. The `kv:` prefix keeps every name apart from PocketBase's own params (`settings`) and from rows extensions
keep there themselves. Write through the helpers, never the table, so the rules above hold.

## Provide

**The wire API and `$kv`:** ext/kv provides `kvv1.Store` by default, over the helpers. Another provider implements
`kvv1.Store` and provides it in `Register` (`kvv1.Contract.Provide(app, s)`); it must keep the storage above, since the
helpers read and write it directly.
