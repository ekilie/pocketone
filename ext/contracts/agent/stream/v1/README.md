# agent.stream/v1

The answers of [agent/v1](../../v1/README.md), handed over as the model writes them instead of all at once, so a page
can show an answer as it appears. A companion of agent/v1 for code in the same process (`pb_hooks`, pages, Go): it
takes a callback, which can't cross an HTTP API, so it has none. Whoever provides agent/v1 provides it too, from the same
backend.

A service contract ([stream.go](stream.go)), one provider.

## Use

From `pb_hooks` or a page, `$agent.stream(opts, onText)` takes agent/v1's options and calls `onText(piece)` as the
answer is written; returning `false` stops it. It returns the whole answer, like `$agent.complete`. A PocketPages
handler can forward the pieces with `ctx.res.sse()`:

```js
// pb_pages/ask/+api.js
module.exports = {
  post(ctx) {
    const { question } = ctx.req.body()
    const stream = ctx.res.sse()
    const r = $agent.stream({ prompt: question, maxTokens: 300 }, (text) => stream.send('text', JSON.stringify(text)))
    stream.send('done', JSON.stringify({ usage: r.usage }))
    stream.close()
  },
}
```

From Go: `streamv1.Contract.Must(app).Stream(ctx, streamv1.Input{CompleteInput: in, OnText: func(s string) bool {...}})`.

## Provide

Implement `streamv1.Streamer` next to `agentv1.Agent`, from the same backend, and provide both in `Register`. It isn't
host-provided: under a multisite host whose instances run in its process (Pocker), the app's provider streams from the
host's model directly.
