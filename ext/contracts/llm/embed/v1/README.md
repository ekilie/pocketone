# llm.embed/v1

A model turns texts into vectors, one per text, for search by meaning. Every call names its model as `provider/model`: a provider the app's admins added in Settings → LLM, a slash, and
that provider's own id for the model. Shared types (`File`, `Usage`, `ModelInfo`, `Job`, the errors) are in
[`pocketone.dev/ext/contracts/llm`](../../llm.go).

A wire contract at `/api/_c/llm.embed/v1` ([embed.go](embed.go)), one provider. The
[llm](../../../../llm/README.md) extension provides it, over Vultr, Cloudflare Workers AI, OpenRouter and any
OpenAI-compatible API.

## Use

In page code it's `$llm.embed` (bound by the llm extension):

```js
const r = await $llm.embed.embedAsync({ model: "cf/@cf/baai/bge-base-en-v1.5", input: ["bedtime story", "lighthouse"] })
r.vectors[0]
```

Over HTTP (a superuser, or a token with the scope shown):

| Operation | HTTP | Body | Token scope |
|---|---|---|---|
| Embed | `POST /api/_c/llm.embed/v1/embed` | `{"model": "...", "input": ["..."], "dimensions": 0}` | `llm` |
| Models | `GET /api/_c/llm.embed/v1/models` | `?provider=` (optional) | `llm:read` |

It answers `{"vectors": [[...]], "model", "usage"}`, in the inputs' order.

Errors: `not_configured` (no providers), `unknown_model`, `not_supported`, `provider` (the cloud's own error), `timeout`.

From Go: `embedv1.Contract.Must(app)` (from `pocketone.dev/ext/contracts/llm/embed/v1`).

## Provide

Implement `embedv1.Embed` and provide it in `Register` (`embedv1.Contract.Provide(app, impl)`). Route on the
`provider/` prefix, answer `not_supported` for a provider that can't do this kind, `unknown_model` for a missing model
or provider, and `provider` with the cloud's own message (never its key) when the cloud refuses. Fill `model` with the
full `provider/model` that answered, and `usage` with what the provider reports.
