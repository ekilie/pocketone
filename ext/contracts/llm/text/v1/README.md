# llm.text/v1

A language model answers a prompt or a conversation, whole or as it's written. With a JSON schema the answer's parsed value comes back as `data`. Every call names its model as `provider/model`: a provider the app's admins added in Settings → LLM, a slash, and
that provider's own id for the model. Shared types (`File`, `Usage`, `ModelInfo`, `Job`, the errors) are in
[`pocketone.dev/ext/contracts/llm`](../../llm.go).

A wire contract at `/api/_c/llm.text/v1` ([text.go](text.go)), one provider. The
[llm](../../../../llm/README.md) extension provides it, over Vultr, Cloudflare Workers AI, OpenRouter and any
OpenAI-compatible API.

## Use

In page code it's `$llm.text` (bound by the llm extension):

```js
const r = $llm.text.complete({ model: "vultr/glm-5.2", system: "Label the ticket.", prompt: body, reasoning: "off",
  schema: { type: "object", properties: { label: { enum: ["bug", "billing", "question"] } }, required: ["label"] } })
r.data.label
$llm.text.stream({ model: "vultr/glm-5.2", prompt: question }, (piece) => { /* show it */ })
```

Over HTTP (a superuser, or a token with the scope shown):

| Operation | HTTP | Body | Token scope |
|---|---|---|---|
| Complete | `POST /api/_c/llm.text/v1/complete` | `{"model": "vultr/glm-5.2", "prompt": "...", "maxTokens": 200}` | `llm` |
| Stream | `POST /api/_c/llm.text/v1/stream` | as Complete; server-sent events | `llm` |
| Count | `POST /api/_c/llm.text/v1/count` | `{"text": "..."}` or `{"system": "...", "messages": [...]}` | `llm:read` |
| Models | `GET /api/_c/llm.text/v1/models` | `?provider=vultr` (optional) | `llm:read` |

`complete` takes `prompt` or `messages` (`[{"role": "user", "content": "..."}]`), and optionally `system`, `schema`,
`maxTokens`, `temperature`, `stop`, `reasoning` (`"off"`, `"low"`, `"medium"`, `"high"`; thinking counts toward
`maxTokens`) and `options` (the provider's own fields). It answers `text`, `data`, `reasoning` (the model's thinking,
when the provider returns it), `stopReason`, `model` and `usage`. `stream` sends one `event: stream` per piece,
`{"text": "..."}` (or `{"reasoning": "..."}`), then `{"done": true, "result": {...}}`. `count` estimates at about four
characters a token.

Errors: `not_configured` (no providers), `unknown_model`, `not_supported`, `provider` (the cloud's own error), `timeout`.

From Go: `textv1.Contract.Must(app)` (from `pocketone.dev/ext/contracts/llm/text/v1`).

## Provide

Implement `textv1.Text` and provide it in `Register` (`textv1.Contract.Provide(app, impl)`). Route on the
`provider/` prefix, answer `not_supported` for a provider that can't do this kind, `unknown_model` for a missing model
or provider, and `provider` with the cloud's own message (never its key) when the cloud refuses. Fill `model` with the
full `provider/model` that answered, and `usage` with what the provider reports.
