# llm.speech/v1

A model reads text aloud and returns the audio as a file. Every call names its model as `provider/model`: a provider the app's admins added in Settings → LLM, a slash, and
that provider's own id for the model. Shared types (`File`, `Usage`, `ModelInfo`, `Job`, the errors) are in
[`pocketone.dev/ext/contracts/llm`](../../llm.go).

A wire contract at `/api/_c/llm.speech/v1` ([speech.go](speech.go)), one provider. The
[llm](../../../../llm/README.md) extension provides it, over Vultr, Cloudflare Workers AI, OpenRouter and any
OpenAI-compatible API.

## Use

In page code it's `$llm.speech` (bound by the llm extension):

```js
const r = $llm.speech.speak({ model: "vultr/qwen3-tts-12hz-1.7b", text: page, voice: "vivian", instructions: "slow and calm" })
record.set("narration", $llm.file(r.file))
$llm.speech.voices("vultr/qwen3-tts-12hz-1.7b")
```

Over HTTP (a superuser, or a token with the scope shown):

| Operation | HTTP | Body | Token scope |
|---|---|---|---|
| Speak | `POST /api/_c/llm.speech/v1/speak` | `{"model": "...", "text": "...", "voice": "", "format": "mp3"}` | `llm` |
| Voices | `POST /api/_c/llm.speech/v1/voices` | `{"model": "..."}` | `llm:read` |
| Models | `GET /api/_c/llm.speech/v1/models` | `?provider=` (optional) | `llm:read` |

`speak` answers `{"file": File, "model", "usage"}`; `voices` answers `{"voices": [{"id", "name", "language"}]}`
(empty when the provider doesn't list them).

Errors: `not_configured` (no providers), `unknown_model`, `not_supported`, `provider` (the cloud's own error), `timeout`.

From Go: `speechv1.Contract.Must(app)` (from `pocketone.dev/ext/contracts/llm/speech/v1`).

## Provide

Implement `speechv1.Speech` and provide it in `Register` (`speechv1.Contract.Provide(app, impl)`). Route on the
`provider/` prefix, answer `not_supported` for a provider that can't do this kind, `unknown_model` for a missing model
or provider, and `provider` with the cloud's own message (never its key) when the cloud refuses. Fill `model` with the
full `provider/model` that answered, and `usage` with what the provider reports.
