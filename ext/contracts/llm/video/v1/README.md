# llm.video/v1

A model makes a video from a prompt (and a first frame). Like music, it's a job. Every call names its model as `provider/model`: a provider the app's admins added in Settings → LLM, a slash, and
that provider's own id for the model. Shared types (`File`, `Usage`, `ModelInfo`, `Job`, the errors) are in
[`pocketone.dev/ext/contracts/llm`](../../llm.go).

A wire contract at `/api/_c/llm.video/v1` ([video.go](video.go)), one provider. The
[llm](../../../../llm/README.md) extension provides it, over Vultr, Cloudflare Workers AI, OpenRouter and any
OpenAI-compatible API.

## Use

In page code it's `$llm.video` (bound by the llm extension):

```js
const job = await $llm.video.createAsync({ model: "vultr/<video model>", prompt: "waves at a lighthouse", seconds: 5 })
// later
const now = await $llm.video.getAsync(job.id)
if (now.status === "done") record.set("clip", $llm.file(await $llm.video.contentAsync(now.id, 0)))
```

Over HTTP (a superuser, or a token with the scope shown):

| Operation | HTTP | Body | Token scope |
|---|---|---|---|
| Create | `POST /api/_c/llm.video/v1/create` | `{"model": "...", "prompt": "...", "image": File, "seconds": 5, "aspectRatio": "16:9", "wait": ""}` | `llm` |
| Get | `POST /api/_c/llm.video/v1/get` | `{"id": "..."}` | `llm:read` |
| Content | `POST /api/_c/llm.video/v1/content` | `{"id": "...", "index": 0}` | `llm:read` |
| Models | `GET /api/_c/llm.video/v1/models` | `?provider=` (optional) | `llm:read` |

The job is the same as [llm.music/v1](../../music/v1/README.md)'s.

Errors: `not_configured` (no providers), `unknown_model`, `not_supported`, `provider` (the cloud's own error), `timeout`.

From Go: `videov1.Contract.Must(app)` (from `pocketone.dev/ext/contracts/llm/video/v1`).

## Provide

Implement `videov1.Video` and provide it in `Register` (`videov1.Contract.Provide(app, impl)`). Route on the
`provider/` prefix, answer `not_supported` for a provider that can't do this kind, `unknown_model` for a missing model
or provider, and `provider` with the cloud's own message (never its key) when the cloud refuses. Fill `model` with the
full `provider/model` that answered, and `usage` with what the provider reports.
