# remote/v1

Remote control of an app from afar: who your credential is and what the app offers, its status, a restart, and its
log. Every client starts here: `GET /api/_c/remote/v1` is the one fixed path, and its answer lists every other
contract the app offers. Contracts that add an area (deploy/v1) require this one.

A wire contract ([remote.go](remote.go)); a multisite host can provide it for its instances, so it works for
instances running stock PocketBase images.

## Use

| Operation | HTTP | Token scope |
|---|---|---|
| Whoami | `GET /api/_c/remote/v1` | public (the answer says more when you're signed in) |
| Status | `GET /api/_c/remote/v1/status` | `remote:read` |
| Restart | `POST /api/_c/remote/v1/restart` | `remote` |
| Logs | `GET /api/_c/remote/v1/logs?n=100` (server-sent events) | `remote:read` |

- **CLI:** `pocketone remote whoami | status | restart | logs`.
- **Go:** `remotev1.Contract.Must(app)` in the app, or `remotev1.NewClient(url, token, http)` from outside. The
  command-line client (linked remotes, saved logins, sign-in) is [remoteclient](remoteclient).
- **Hooks:** `remotev1.OnRestart(app)` in Go, `onRemoteRestart` in `pb_hooks`, for every operation.
- **MCP:** a tool per operation (`remote_status`, ...).

## Provide

Implement `remotev1.Remote` and provide it in your extension's `Register`:

```go
remotev1.Contract.Provide(app, myRemote{})
```

A multisite host provides it for every instance with `remotev1.Contract.ProvideForInstances(host, factory)` and
serves it with `remotev1.W.HostHandler` in its instance routes (`multisite.Host.InstanceRoutes`, after the gates;
see [pocker](../../../pocker/README.md) and
[docker](../../../docker/README.md)).
