# bulkmail/v1

Campaigns to many recipients, sent at a pace the app's mail account can take. Campaigns are records in the
provider's collection, created and edited with PocketBase's records API; this contract runs them. The list of
addresses never to mail is [mail.suppression/v1](../../mail/suppression/v1/README.md); providers' bounce and
complaint reports are [mail.feedback/v1](../../mail/feedback/v1/README.md).

A wire contract ([bulkmail.go](bulkmail.go)).

## Use

| Operation | HTTP (`POST`) | Body | Token scope |
|---|---|---|---|
| Count | `/api/_c/bulkmail/v1/count` | `{"audience": {...}}` | `bulkmail:read` |
| Start | `/api/_c/bulkmail/v1/start` | `{"campaign": "<id>", "limit": 0}` | `bulkmail` |
| Pause, Resume, Cancel | `/api/_c/bulkmail/v1/pause` (`resume`, `cancel`) | `{"campaign": "<id>"}` | `bulkmail` |
| Preview | `/api/_c/bulkmail/v1/preview` | `{"campaign": "<id>", "email": ""}` | `bulkmail:read` |
| Test | `/api/_c/bulkmail/v1/test` | `{"campaign": "<id>", "to": ""}` | `bulkmail` |

Campaign actions answer `{"campaign": <the record>}`. The audience's shape is the provider's (see
[Bulk Mail](../../../bulkmail/README.md)). Only superusers may call these. Agents get them as MCP tools
(`bulkmail_start`, ...); `pb_hooks` can hook each (`onBulkmailStart`).

## Provide

Implement `bulkmailv1.Campaigns` and provide it in your extension's `Register`.
