# Getting started

## Install

Download the app for your system from the releases page and unzip it. It's one file with no dependencies.

## First run

Start it with `myapp serve`. It opens on port 8090; visit http://127.0.0.1:8090 and sign in with the account you
created during setup.

## Updating

Run `myapp upgrade`. Your data stays where it is, and the previous version is kept beside the new one in case you want
to go back.
